# Datasheet

Our omni-channel retail platform is organized into the following solution
areas. Over 3,000 POS implementations have been delivered for more than 200
clients across Asia Pacific.

| Module | Description |
| --- | --- |
| Retail POS Software | Omni-channel fulfilment, fresh design, scalable, multi-currency and extendable. |
| E-commerce | E-commerce, mobile commerce and social commerce, unified with in-store fulfilment. |
| CRM | Unified customer profiles across channels with standardized privileges. |
| Staff Productivity | Predictive analytics, in-context alerts and consolidated execution views for retail staff. |
| Consumer Engagement | Consistent, attributable messaging across channels to assess marketing efficiency. |
| Inventory Management | Optimized stock holding across stores and selling channels. |
| Reporting and Analytics | Intuitive, holistic reporting across PC, mobile and other devices — see [Reporting](./reporting). |
