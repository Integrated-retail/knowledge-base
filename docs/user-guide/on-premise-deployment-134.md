For on-premise deployments:

## Typical steps

1.  Complete [Server Installation](./server-installation) at the primary site.
2.  Deploy POS terminals per the [Installation Guide](./installation-guide).
3.  Configure local network and, if applicable, connectivity back to head office for consolidated reporting.
4.  Establish a local backup routine per the Backup Policy.
